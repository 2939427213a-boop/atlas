What Astra changed for computer use

Astra

进步在边角上

one-liner

Astra 之前，Sol 已经很会用电脑。Astra 的进步在边角上：更快、更可靠、更对齐。Ari 说他“更信任它一点”，James 说企业用起来会“安全得多”。

要点
  1. Ari：稍快一点。做同一个任务，它用的思考 token（thinking tokens）更少，所以平均快一点。
  2. Ari：更会做创意活。发布视频里，你一边说，它一边在 Microsoft Paint 里画。
  3. Ari：更可靠。99% 和 97% 的可靠度，差别很难察觉，但很重要；他“更信任它一点”。

When computer use becomes superhuman

超人

比专家快的那一天

one-liner

Ari：要盯着看或等结果时，速度决定用 agent 是否比自己动手划算。它已经比普通人快，正接近比专家快；到那时，手动能做的事默认都会交给 agent。

要点
  1. 他的说法：OpenAI 有“最快、最便宜、最可靠”的 computer use 产品，而且还能走得更远。
  2. 为什么在乎速度：后台任务慢点没关系。但你要盯着它确认，或后面的事要等它时，慢会让人觉得“不如自己做”。
  3. 现状：已比普通人用电脑快；正接近 superhuman，即比专家（“比如这张桌上的我们”）还快。他称之为“巨变”（sea change）。
  4. 多模型、多价位：便宜的模型，computer use 也在快速变好。以后不同任务会用不同模型，选择更分散。

How much autonomy to give agents

放手

盯不过来之后，怎么管

one-liner

James：agent 快到人盯不过来时，要能调“人在环中”的多少，还要能事后审计。他说随 Astra 推出了一套企业管控，还提到一个审核 agent 动作的模型 Guardian。

要点
  1. 慢的悖论：慢的时候你能看着它，但只能交给它“值得坐着看”的事，反而低效。
  2. 快了之后：人看不过来。企业需要两样东西：控制人在环中（human-in-the-loop）的程度，和事后可查（auditability）。
  3. 企业管控：随 Astra 推出。企业可以全部自动批准，也可以要求人批准。
  4. Guardian（他说 app 里叫 auto-approve）：一个很聪明的模型，看 agent 的每一步，判断是否安全、是否符合最初的意图。
  5. 因人而异：消费者可能只想“全做了，别问我”；企业自己定。agent 越超人，控制越重要。

Guardian 审核James：模型看每一步，安全吗？符合原意吗？
全部自动最快

先问“能不能交给 agent”

one-liner

one-liner

要点

老软件会长期存在，computer use 正好能操作它们。做软件变便宜，会逼软件更好用、更个性化；人又偏爱亲手操作，所以界面不会消失。

要点
  1. 主持人Seema 的问题：企业会留着 30 年前的笨重 ERP，让 agent 在上面操作？还是 AI 原生的新软件取而代之？
  2. Ari：两者都会长期存在。生产环境里很多软件是 10–40 年前写的，不会一夜消失。computer use 可能会逼软件更适配 agent，WebMCP 就是例子。
  3. James：不想要“没人用界面”的互联网。他给妻子做了一个五子棋（Omok）战术训练器，按她喜欢的学法定制。复盘总结可以交给 agent，但下棋本身要人练。
  4. Ari：人天生偏爱直接操作（direct manipulation）。过去软件为几百万到几十亿人设计；以后可以只为 100 个人、甚至 1 个人设计。

四个浏览器，互不相通

one-liner

下一步是更快、更会实时协作、更主动；还要把散在各处的浏览器和电脑，统一成普通人能理解的一套体验。

要点
  1. Ari：下一步。更快，做到 superhuman，把不同界面、多模态的输入输出揉在一起。现在的产品偏后台（交代任务，你去忙别的），以后会有更多实时协作。
  2. James：四处分散。见下图。普通用户会问：为什么我有四个互不相通的浏览器？
  3. James：一个悖论。computer use 本是最好懂的 AI 产品（AI 在用你的电脑），但状态和位置太多，实现细节漏给了用户。他最期待下个季度做到 consumer grade：更好懂、更连贯。
  4. Ari：主动性。现在你得记得用它、想好怎么用、说服自己改习惯。他希望 agent 适应你，而不是你适应它；目标仍由人设定。

Computer use's scaling moment

拐点

从桌面到每个人的手机

one-liner

模型今年才变得好用，产品最近两个月快速增长。下一个拐点是云端电脑：把 computer use 带给只用手机的普通人。

要点
  1. Ari：曲线。6–9 个月前做这些产品时几乎没人用；今年早些时候，模型突然擅长这类任务；最近两个月产品“疯长”。但只有一部分用户在用，还很早。
  2. James：Atlas 的教训。他 1 月加入 OpenAI 做 Atlas 浏览器，“RIP Atlas”。在 Atlas 里，agent 功能不是卖点，多数人把它当普通浏览器。后来浏览器和 browser use 被放进人们本来就用 agent 的产品，周增长像 YC 公司。
  3. James：下一个拐点在云端。桌面仍是 power user 的东西，多数人用手机。要给每个人一台不用懂怎么用的强大电脑。
  4. Ari 收尾：computer use 正处在规模化时刻，消费端和企业端同时。
